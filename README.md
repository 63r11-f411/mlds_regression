# House Prices — Advanced Regression Techniques

Решение соревнования [Kaggle House Prices](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques): регрессия цены дома по 79 признакам. Метрика — RMSE между логарифмами предсказанной и реальной цены.

Модели: Ridge (бейзлайн), Lasso, ElasticNet, KNN, решающее дерево, XGBoost, CatBoost, MLP на PyTorch, а также voting и stacking поверх них. Все модели — sklearn-пайплайны со своей предобработкой. Оценка — 5-фолдовая кросс-валидация.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и Kaggle API токен (а также принятые правила соревнования на Kaggle).

```bash
uv sync                          # окружение из uv.lock
uv run python dataset_load.py    # данные в ds/
uv run python main.py            # CV + сабмит в submission/
```

По умолчанию запускается итоговая модель — stacking (Ridge + CatBoost + MLP). Её CV считается несколько минут.

Что запускать, задаётся в `RunConfig` в `config.py`:

| Поле | Что делает |
|---|---|
| `models` | какие модели запустить: `ridge`, `lasso`, `elasticnet`, `knn`, `tree`, `xgb`, `catboost`, `nn`, `voting`, `stacking` |
| `tune_hyperparameters` | подбор гиперпараметров; лучшие сохраняются в `best_params/` |
| `use_saved_params` | собирать модели с параметрами из `best_params/` |
| `cross_validate` | посчитать CV, результат дописывается в локальный лог `scores.txt` (не в репозитории) |
| `save_test_results` | обучить на всём train и сохранить сабмит |
| `ensemble_members` | из каких моделей собирать voting и stacking |

Сетки поиска — в файлах `models/`, ручные параметры (`model_params`) — в `models/__init__.py`. Ручные параметры перекрывают сохранённые.

## Результаты

| Модель | CV RMSE | Kaggle (public) |
|---|---|---|
| Ridge (бейзлайн) | 0.1127 | 0.12379 |
| Lasso | 0.1110 | 0.12584 |
| ElasticNet | 0.1111 | 0.12503 |
| KNN | 0.1592 | 0.15906 |
| Решающее дерево | 0.1883 | 0.18743 |
| XGBoost | 0.1145 | 0.13169 |
| CatBoost | 0.1140 | 0.12446 |
| MLP | 0.1175 | 0.12564 |
| Voting (Ridge + CatBoost + MLP) | 0.1095 | 0.12015 |
| **Stacking** (те же модели, мета-модель LinearRegression) | **0.1092** | **0.12012** |

CV посчитан на текущем коде с сохранёнными параметрами. Параметры подбирались на тех же фолдах, поэтому CV немного оптимистичен; оценки с вложенной CV — в `experiments.md`. Kaggle-скоры линейных моделей, KNN, дерева и XGBoost получены до добавления порядковых `LotShape` и `LandSlope`, на CV это изменение в пределах шума.

Главные выводы:
- **Ridge с хорошим FE — сильный бейзлайн, который одиночные модели не обгоняют.** Лог-цена почти аддитивна по признакам, предобработка сделана под линейную модель, а данных мало (1460 домов). XGBoost при подборе каждый раз выбирал деревья глубины 2–3, то есть сам приходил к почти аддитивной модели.
- **Лучший результат дал ансамбль** моделей, устроенных по-разному: линейной и бустинга. MLP на том же препроцессоре, что и Ridge, в ансамбль почти ничего не добавляет.
- **Больше всего на LB помогли предобработка и регуляризация Ridge** (логарифм площадей с флагами наличия, подбор α), а не выбор модели.

Подробности экспериментов — в `experiments.md`.

## Структура

- `EDA_house_prices.ipynb` — разведочный анализ
- `experiments.md` — эксперименты и выводы
- `feature_engineering.py`, `preprocessing.py` — признаки и три варианта предобработки (для линейных моделей и сети, для деревьев, для CatBoost)
- `models/` — модели и реестр `MODELS`
- `utility.py` — кросс-валидация, поиск параметров, сохранение результатов
- `best_params/` — подобранные гиперпараметры
